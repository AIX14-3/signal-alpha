# docs/archive — 보존용 과거 문서

이 폴더의 문서들은 **과거 기획·탐색·설계 사료**입니다. 최신 구현 기준이 아니며,
현재 동작을 판단하는 근거로 사용하지 마세요.

최신 기준 우선순위:

1. 현재 브랜치의 실제 코드와 테스트
2. DB 스키마 → `database/migrations/`
3. 루트 `README.md`, `AGENTS.md`, 각 서비스/패키지 README
4. `docs/` 의 현행 문서 (`docs/README.md` 참조)
5. `docs/spec/` 기술 스펙

> 여기 있는 내용 중 여전히 유효한 부분은 위 현행 문서/스펙으로 옮겨졌습니다.
> 이 폴더는 히스토리 참고용으로만 유지합니다.
