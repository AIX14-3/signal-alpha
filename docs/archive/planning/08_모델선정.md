## 8.1 LLM — 멀티 프로바이더 비교

### 워크로드 정의

| 작업 유형 | 특성 | 요구 수준 |
| --- | --- | --- |
| 분석·요약·토론 | 짧은 한국어 + JSON 출력, 호출 다수, 수치는 DB 주입 | 중간 |
| 심판(Judge) | 양측 논거 종합, 추론 품질 중요 | 높음 |
| 단순 분류 | 키워드 분류, 대량 처리 | 낮음 |
| 리포트 밸류에이션 분류 | 정리된 리포트 fact 기반 methodology/category/thesis 분류, 수치 생성 금지 | 중간 |
| 멀티 AI 투표 | 판단 독립성 위해 타사 혼합 | 중간 |

### 분석·요약·토론용 (메인 워크로드)

| 제공사 | 모델 | 입력 | 출력 | 컨텍스트 | 판정 |
| --- | --- | --- | --- | --- | --- |
| Google | Gemini 3 Flash | $0.50 | $3.00 | 1M | ★ 기본값 |
| OpenAI | GPT-5 Mini | $0.25 | $2.00 | 400K | 후보 |
| OpenAI | GPT-5.4 Mini | $0.75 | $4.50 | — | 후보 |
| Anthropic | Claude Haiku 4.5 | $1.00 | $5.00 | 200K | 후보 (한국어 안정) |
| Google | Gemini 3.5 Flash | $1.50 | $9.00 | 1M | 심판 보강용 |

**선택**: Gemini 3 Flash. 한국어·JSON 안정성, 1M 컨텍스트로 긴 리포트 처리, 가성비 균형. GPT-5 Mini가 입력 단가는 더 싸나 한국어·긴 컨텍스트에서 Gemini가 유리.

### 단순 분류용 (직군·카테고리, 대량 처리)

| 제공사 | 모델 | 입력 | 출력 | 판정 |
| --- | --- | --- | --- | --- |
| OpenAI | GPT-5 Nano | $0.05 | $0.40 | 최저가 |
| Google | Gemini 2.5 Flash-Lite | $0.10 | $0.40 | ★ 채택 |
| OpenAI | GPT-5.4 Nano | $0.20 | $1.25 | 대안 |

**선택**: Gemini 2.5 Flash-Lite. 분류는 품질 요구가 낮아 최저가권이면 충분. 메인 모델과 같은 생태계로 통합 관리.

## 8.2 임베딩 모델

| 후보 | 비용 | 특징 | 판정 |
| --- | --- | --- | --- |
| BGE-M3 | 무료 (자체 호스팅) | 다국어·한국어 강, 8K, 밀집+희소 하이브리드 | ★ 채택 |
| Kanana (카카오) | 무료 (자체 호스팅) | 한국어 특화, 경량·저지연 | 대안 |
| Qwen3-Embedding | 무료 (자체 호스팅) | 벤치마크 최상위, 모델 큼 | 성능 보강 시 |
| Gemini Embedding | $0.15 / 1M | 교차언어 최상 | 자체 호스팅 불가 시 |

**선택**: BGE-M3. 무료 자체 호스팅, 한국어 검증, 하이브리드 검색이 긴 리포트 PDF에 유리. 스키마는 1024차원으로 고정되어 있다 (`report_chunks.embedding VECTOR(1024)`) — 임베딩 모델 교체 시 차원 정합 필수.

## 8.4 오픈소스 자체 호스팅 (참고)

데모 단계에선 비추천이나, 비용·데이터 주권이 중요해지면 고려.

| 모델 | 라이선스 | 비용 | 비고 |
| --- | --- | --- | --- |
| Qwen3 계열 | Apache 2.0 | 자체 호스팅 약 $0.20~0.34/M | 상업적 사용 자유, 한국어 양호 |
| DeepSeek V4 Flash | API 우선 | $0.14 / $0.28 | API로 1M 컨텍스트, 매우 저렴 |
| Gemma 4 | 제한적 | 경량 로컬 | 소형 로컬 추론 |

**판정**: 6주 프로젝트에선 API가 합리적. 자체 호스팅은 GPU 인프라 부담이 커 보류.
