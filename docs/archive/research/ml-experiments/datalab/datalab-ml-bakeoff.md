# DataLab 단독 ML 모델경연 보고서 (2026-06-23)

> 대체데이터(검색 트렌드) **단독**으로 종목의 미래 (초과)수익률을 예측할 수 있는가를
> 검증한 트랙. **모델 경연(bake-off) 하니스**를 새로 구축하고, DataLab을 2021~2023
> 전체 적재한 뒤 모델 16종을 워크포워드로 평가했다. 환경·데이터 출처·방법론·결과·근거 포함.
> 
> **한 줄 결론: 삼성·하이닉스·네이버 3종목 · DataLab 단독으로는 어떤 horizon에서도 예측 신호가 없다.
> 2021만 볼 때 보였던 h=10 리드는 소표본 우연이었고 3년 데이터에서 소멸했다.**

## 2. 실행 메타

- 브랜치: `feat/altdata-per-source-final-signals` (ML 하니스는 신규 `app/ml/`, 현재 미커밋)

### 3.2 수집 자료 (2개 소스)

| 자료 | 출처/API | 저장 | 행수 | 기간 |
| --- | --- | --- | --- | --- |
| DataLab 검색 트렌드 | **Naver DataLab** 검색어 트렌드 API (카테고리별 일별) | Supabase `datalab_raw_documents/details` | **77,116** (2021=25,032 / 2022~23=52,084) | 2021-01-01~2023-12-31 |
| 일봉 종가 + KOSPI | **FinanceDataReader**(무료·키 불필요) | 로컬 CSV `prices_2021_2023.csv` | 3,200 (800×4) | 2021-01-01~2024-03-31 |

- DataLab은 **종목당 카테고리(검색 테마)** 로 수집(24개 카테고리, 키워드 93개). 카테고리↔종목 매핑은
`datalab_category_stocks`, 폴라리티(demand/risk)는 `datalab_category_keywords`.

- 주가는 키움(모의키·실시간용)이 과거 백필에 부적합 → **FinanceDataReader**로 대체. KOSPI 지수(`KS11`)는
초과수익률 벤치마크. **`ohlcv_data`(주가팀 테이블)는 건드리지 않음** — 주가는 CSV로만 흐름.

### 3.3 왜 이 자료들인가 (근거)

- **예측 대상 = 미래 초과수익률**(종목 − 시장). 단순 수익률은 "시장이 올라서 다 오른" 부분이 섞여
신호의 종목 고유 실력을 못 잰다. 특히 단일 국면 위험이 큰 짧은 표본에서 필수.

- **DataLab 단독**: 제품 설계는 다중 소스 후기 융합이지만, 먼저 **한 소스의 1층 모델**이 단독으로
주가를 맞히는지부터 검증(배관 + 신호 유무).

- **2~3년 일별 + 주간 신호**: 인접일 자기상관을 줄이려 주간(5거래일) 단위로 신호를 샘플링.
### 3.4 데이터 신뢰성 근거 / 함정

- **Naver 백필 무결성**: 2021 `inserted=25,032 skip=0 fail=1`, 2022~23 `inserted=52,084 skip=0 fail=0`.
재실행 안전(중복 관측 UniqueViolation skip).

- **주가 sanity**: 삼성전자 2021-01-04 종가 83,000원 → 2023-12-28 78,500원(실제와 일치). KOSPI 2944→2655(일치).
- **누수 차단(백테스트)**: 피처는 `observed_date ≤ 신호일`만, 라벨은 신호일 *이후* 주가만. 워크포워드는
날짜 경계로 분할(같은 날 train/test 혼입 금지). → 단위테스트 18개로 검증.

- **부작용**: 수집기가 레코드마다 `processing_queue`에 NORMALIZE_DATALAB을 적재(워커 없으면 pending만 쌓임, 무해).
### 3.5 가공 파이프라인

- `app/ml/datalab_dataset.py`: 종목·신호일별로 `analyzers/datalab/indicators.compute_indicators`(**실서비스 피처 로직 재사용**)를
돌려 10개 피처(momentum_pct·spike_ratio·risk_momentum_pct·avg_change_pct·observations 등) 생성.

- 라벨(`app/ml/labels.py`): 초과수익률 → 중립밴드(±0.3%) 밖만 up/down, 안쪽은 드롭.
- 입력 설계: **1층 = 가공 피처(indicators) + (해당 시 기존 점수)**, 통합(2층)은 점수만(이번 런은 1층 단독).

## 4. 방법론 (모델 경연 하니스 `app/ml/`)

- **모델 16종**(공통 fit/predict): baseline(majority·stratified), 로지스틱·ridge·LDA·나이브베이즈,
결정트리·랜덤포레스트·ExtraTrees·GradientBoosting·HistGB, KNN·SVM(RBF)·가우시안프로세스, Voting·Stacking.

(XGBoost/LightGBM/CatBoost는 선택 설치 — 로컬 미설치라 이번 런 제외, 레지스트리가 자동 스킵.)

- **평가**: 시계열 **워크포워드 5-fold**(확장 윈도우). 지표 4묶음:
- A 방향: accuracy·precision·recall·f1·roc_auc + **Dbase**(다수 baseline 대비 Δ)
- B 크기: **IC**(Pearson)·**Rank-IC**(Spearman) — 점수 vs 실제 초과수익률
- C 경제성: 점수 상위10%−하위10% 수익률 스프레드(decile_spread)
- D 견고성: 모든 지표를 **fold 평균±표준편차 + 표본 수**로 — 한 fold의 운을 차단
- **판정 규칙**: ❶baseline보다 유의하게↑ ❷IC>0 ❸점수↑→적중률↑ 단조 ❹fold 표준편차 작음.

## 5. 무결성 검증 (통과)

- 모든 런에서 16개 모델 전부 평가됨(조용한 skip 없음). 드롭 사유는 `dropped=`로 노출(neutral_band·no_forward_price).
- 단위테스트 18개 GREEN: 라벨 로직(중립밴드·초과수익률·is_hit) + 워크포워드 누수 가드 + DataLab 빌더(룩백 누수·라벨 기간·드롭) + CSV 로더.
- 백필 행수 DB 직접 검증(연도별 count로 진척·완결 확인).

## 7. 통계 해석 · 판정

- **판정(확정): DataLab 단독으로는 미래 초과수익률 예측 불가 — 3종목→15종목(섹터 다양)·~1,900샘플·
전 horizon에서 일관.** 처음엔 "3종목이라 못 본다"는 가설이 남아 있었으나, 종목을 5배로 늘려도

중앙값 rankIC≈0 이 유지되고 **이번엔 sd_IC가 작아 "확정적 0"**(불확실한 무신호가 아님) → 가설 기각.

- 2021 h=10 리드는 **소표본 과적합(우연)** — 데이터를 3배로 늘리자 rankIC +0.27 → −0.03으로 붕괴.
2021 런의 `sd_IC ≈ IC` 경고가 이를 정확히 예고했다.

- **방법론적 성과**: 하니스가 **신기루를 잡아냈다.** 2021에서 멈췄다면 "DataLab은 2주 예측에 효과 있다"는
거짓 결론을 낼 뻔했다. **"데이터를 늘렸을 때 죽는 신호는 진짜가 아니다"** 를 실데이터로 확인.

- **함의**: 단일 약신호가 혼자 주가를 맞히는 일은 드물다 → 제품의 **다중 소스 후기 융합** 설계가 정당.

## 8. 이상치 · 주의

- **다중비교**: horizon 5개 × 모델 16개를 보면 일부가 우연히 좋아 보인다(2021 h=10). 그래서 **out-of-sample/추가
데이터 재검증**이 필수였고, 실제로 그 검증에서 리드가 사라졌다.

- **표본 규모**: 전체에서도 n≈411(주간·3종목)로 게이트(1,000+)에 미달. "신호 없음"은 **확정적 부정이라기보다
이 표본에서 검출 불가**로 읽는 것이 정확.

- **결과 파일**(results_*.csv·prices CSV)은 로컬 산출물(레포 비추적). prod에 DataLab ~77k행 + queue pending 적재됨.
