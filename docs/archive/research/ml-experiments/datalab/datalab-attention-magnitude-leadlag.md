# 어텐션 → 매그니튜드(변동성·거래량) 선행성 — 견고 (2026-06-26)

> 방향 알파는 단일소스·대형·소형·검색→펀더멘털 전부 기각. 유일하게 robust했던 "어텐션=매그니튜드"
> 가설을 전수(250)·전기간(2016~2023)·era분할로 본격 검정 — *방향*이 아니라 *변동성·거래량*을 선행하는가.
> 제품 "주목/주의 플래그" 후보.
> 
> **한 줄 결론: 검색 abnormal(과거대비 급증, PIT)이 차기 거래량·변동성을 강하게 선행 — 미래 abnormal거래량 IC +0.370(t 40.7), 미래 변동성 +0.195(t 22.2). ①과 달리 2016~2020 평시(+0.351, t29.8)와 2021~2023(+0.401)에서 동일하게 강하고 KOSPI·KOSDAQ 모두 일관(KOSDAQ +0.48로 더 강). PIT·forward·비중첩·전수·전기간이라 look-ahead·기간·유니버스 아티팩트 아님. 프로그램 전체에서 처음으로 완전히 견고한 신호 — 단, 방향이 아닌 매그니튜드(제품 흔적/주의 플래그).**

## 1. 실행 환경

| 항목 | 값 |
| --- | --- |
| 실행기 | 로컬 Windows 11 (CPU) |
| Python / 라이브러리 | 3.11.15 · pykrx · FinanceDataReader · 자체 통계 |
| 데이터 출처 | 네이버 DataLab(검색) · pykrx(일간 종가·거래량) · FDR(유니버스) · DB 미사용 |

## 2. 실행 메타

- 코드 위치: worktree `sa-ml-longhorizon` working tree(미커밋). prod 쓰기 0.
- 예측자(PIT): `abn` = 종목명 검색량의 과거 60거래일 rolling z(과거-only). 주간검색을 거래일로 forward-fill(과거값만 사용 → PIT 보존).
- 타깃(미래): ① 미래 실현변동성 = 향후 h거래일 일간 로그수익 std. ② 미래 abnormal 거래량 = 향후 h일 평균거래량 / 과거 60일 평균. (대조: 과거 h일 동시 변동성)
- 평가: **비중첩 참조일**(간격=h) 횡단면 IC 평균 + t. era×market 분할.
## 3. 데이터 — 유니버스 · 자료

- 유니버스: KRX 시총상위 250(KOSPI 190 / KOSDAQ 60), SPAC·관리·환기·외국·리츠 제외. 가격∩검색 보유 **191종목**.
- 자료:
| 자료 | 출처 | 저장(로컬·비추적) | 규모 | 기간 |
| --- | --- | --- | --- | --- |
| 일간 종가·거래량 | pykrx | `prices_krx250.csv` | 238종목 | 2016~2023 |
| 종목명 주간 검색 | DataLab | `stockname_krx250.csv` | 194종목 | 2016~2023 |

- 누수 차단: 예측자(검색 abn)는 과거-only rolling z + 과거값 forward-fill, 타깃은 t+1~t+h(미래), 참조일 비중첩 → t-stat 정직.
- 한계 메모: 일간 검색은 DataLab 일일쿼터(HTTP 429) 소진으로 미수집 → 주간검색 forward-fill로 측정(=보수적; 일간이면 더 선명할 것).
## 4. 방법론 (판정 규칙)

- 횡단면 IC = 분기/구간마다 종목 횡단 corr(검색abn, 미래 매그니튜드) → 평균 + t.
- **판정**: 미래 vol/volume IC>0 & |t|>2 & **era 전반 일관**이면 견고. (①의 교훈 — 2021~23만 유의하면 기각.)

## 6. 해석 · 판정

- **확정 채택(매그니튜드).** 검색 abnormal은 차기 거래량(IC +0.37)·변동성(+0.20)을 강하게 선행. 평시(2016~20)에도 +0.35로 견고 → 레짐/기간 아티팩트 아님. KOSDAQ에서 더 강(소형·리테일 집중과 정합).
- **방향이 아니라 매그니튜드.** "오른다/내린다"가 아니라 "관심·거래·변동성이 몰린다/몰릴 것" = 제품 [[product-vision-scoring]]의 흔적 탐지·근거 제시·confidence회피 프레이밍과 정합. 트레이딩 방향 알파로 쓰면 안 됨(방향은 전 실험 기각).
- 거래량 신호가 변동성보다 강함(검색-거래 관심이 거의 동일 construct). 미래(t+1~5)에서도 동시 못지않게 강 → 짧은 선행성 실재.
## 7. 이상치 · 주의 / 한계

- **주간검색 forward-fill**: 일간 쿼터 소진으로 주간을 거래일에 채워 사용(stepwise) → 보수적. 일간 재수집(쿼터 리셋 후)으로 더 선명화 가능.
- 거래량 일부는 기계적(검색=거래 관심 근접 construct). 동시>미래는 자연스러움. "방향 무관 매그니튜드"임을 명확히.
- 생존편향(현재상장만). 데이터·로그 git 비추적.
