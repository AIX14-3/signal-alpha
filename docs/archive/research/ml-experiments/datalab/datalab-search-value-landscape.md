# DataLab 검색 가치지형 종합 — 매그니튜드·방향·매출·PEAD (2026-06-30)

> worktree `sa-ml-longhorizon` @ `feat/ml-datalab-longhorizon`. prod 읽기전용, 데이터 산출물 미커밋(연구), 도구만 브랜치 커밋·push(머지 보류).
> **한 줄 결론: DataLab 검색의 가치는 비방향에 있다 — 방향은 전 키워드 NULL, 매그니튜드(변동성/거래량)는 반석, 차기매출 level은 robust 나우캐스트(검색→매출 +0.051 q0.002). 단 매출 서프라이즈는 검색이 못 잡고(NULL) PEAD 거래신호는 DART 매출 서프라이즈(SUE→드리프트 decile +2.24%)에 있어 검색은 독립 PEAD 알파가 아니다 = 검색은 매출 level 나우캐스터.**

## 1. 매그니튜드 ML 모델 선정 (검색 → 미래 변동성/거래량)

회귀 bake-off(16모델 walk-forward, KOSDAQ 46종목 2021~23) 신규 추가:

- **변동성**: linear/ridge가 최적(rankIC +0.15~0.19). 신호가 abn에 **선형** → ML이 단순 z-score를 못 이김(트리계열 과적합 음수 R²).
- **거래량**: **비선형 압승** — svm_rbf rankIC +0.31~0.44, GBM/RF +0.37~0.39·R²+0.09. 단변량 abn IC(+0.30) 유의 상회 → ML 도입 가치.
- 두 매그니튜드의 성질이 다름: 변동성=선형, 거래량=비선형. 티어링엔 svm, 배수추정엔 GBM/RF.

## 3. 방향성 PIT 재검정 — 의도한 키워드 방법론으로

직전 "방향 기각"이 종목명·특허키워드 기반이었고 **설계 의도(뉴스/DART 1차정보 PIT 키워드)는 미검정**임을 감사로 확인 → 재검정:

- **수요·제품 키워드**(합성 다중키워드, 21종목): 방향 IC ≈0, 16모델 베이스라인 못 이김 → **NULL**.
- **DART 공시 이벤트 키워드**("[종목명] 유상증자/자사주매입/소송…", PIT rcept_dt 앵커, 154개): 합성·PIT게이팅 bakeoff 모두 → **NULL**.
- 빅카인즈 유료 전환으로 제외, 웹서치는 후견편향(non-PIT)으로 미채택.
- **결론: 방향 기각이 키워드 방법론 전반(설계 의도 포함)으로 확정.**
## 4. 검색 → 차기 매출 재검정 @219 ★뒤집힘

"매출값 없었던 것 아닌가" 확인 → **매출값 실재**(602/609행 채워짐). R2(39종목)가 강등된 건 데이터가 아니라 **표본이 작아서**. **219종목(dart_krx250 매출 2015~23 + name-search)으로 재실행**:

- 횡단면 IC lag1 **+0.051(t2.73)**·lag2 +0.073, 20/28분기 양수, LOO 안정.
- **permutation+BH-FDR 9/10 셀 생존**(헤드라인 q0.002). 39종목서 강등됐던 신호가 **큰 횡단면서 robust**(wide-null → tight-null).
- 횡단면 효과(firm pooled r≈0), 2021~23 era 집중(+0.100 t3.41).
- **매그니튜드 외 처음으로 정직검정 통과한 신호. 사용자의 "더 큰 표본" 직감 적중.**
## 5. 검색 → 매출 → 주가 사슬 + PEAD 분해

검색이 매출을 예측한다면 주가까지 가는가:

- **검색 → 차기주가 직접 = NULL**(lag1 +0.005 p0.69). 매출은 발표 시점 즉시 반영(efficient pricing).
- **PEAD(발표후 드리프트)**: 발표 전 검색 → 발표후 20~40일 드리프트 = +0.035·p~0.01(10일은 NULL=즉시반응 효율적). 약하나 슬로우 언더리액션 존재.
- **서프라이즈(SUE) 분해**가 결정적:
| 검정 | IC | perm_p | decile% |
| --- | --- | --- | --- |
| T1 SUE(매출서프라이즈)→드리프트 | +0.045 | 0.0045 | **+2.24** |
| T2 검색→SUE | +0.014 | 0.36✗ | −0.39 |
| T3a 검색→드리프트 raw | +0.035 | 0.0075 | +0.54 |
| T3b 검색→드리프트 \ | SUE통제 | +0.020 | 0.20✗ |

- **PEAD는 실재·경제적**: 매출 서프라이즈 → 드리프트 decile **+2.24%**(상위10% 서프라이즈가 20일간 더 드리프트).
- **검색은 서프라이즈를 못 잡고**(T2 NULL), 검색의 드리프트 예측은 **SUE 통제 시 소멸**(T3b NULL) → 검색의 약한 PEAD는 서프라이즈의 노이즈 프록시였을 뿐.
- **결론: 거래 가능한 PEAD는 DART 매출 서프라이즈(SUE)가 만들고, 검색(DataLab)은 그 너머를 추가 못 함. 검색 = 매출 level 나우캐스터.**
## 6. 부수 결과

- **DART 이벤트스터디**(검색 우회, 사건→주가 CAR, 신규 `dart_event_study.py`): @21종목 BH 생존 0/45(무상증자/횡령/유상증자만 원시 p<0.05, 소표본). @250 확장은 후순위.
- **name-search 방향 @250**(231종목): 횡단면 IC +0.031(t4.83) 양성이나 16모델 베이스라인 못 이김·경제적 미미 = 거래불가.
## 종합 — 검색 가치지형 (확정)

- **방향 알파**: 전 키워드(종목명·의도·특허·수요·DART이벤트) NULL → 종결.
- **매그니튜드**(변동성/거래량): 반석(IC +0.15~0.30, 제품화 attention_spike).
- **차기매출 level 나우캐스트**: robust 양성(검색→매출 +0.051 q0.002).
- **PEAD 알파**: 검색 아님 — DART 매출 서프라이즈(SUE→드리프트 +2.24% decile)에 있음.
- cf. 채용→매출 나우캐스트 발견과 정합 — **대체데이터의 가치는 "매출 나우캐스트"에 수렴**, 주가 방향/PEAD 알파 아님.
