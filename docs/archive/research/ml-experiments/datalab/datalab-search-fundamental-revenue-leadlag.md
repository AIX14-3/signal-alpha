# 검색 → 펀더멘털(차기 분기 매출) 선행성 — 레짐 조건부 (2026-06-26)

> 검색 어텐션이 *주가*는 못 움직여도 *펀더멘털(분기 매출)*은 선행하는가? (제품 원래 가설의 첫 고리)
> KOSPI+KOSDAQ 시총상위 250종목·2016~2023, 검색 abnormal(과거대비 급증, PIT) → 차기 분기 매출 YoY를
> 횡단면 IC로 검정. DART 공개 API(읽기·로컬)로 분기 매출 수집.
> 
> **한 줄 결론: 검색 abnormal이 차기 분기 매출 YoY를 선행하는 효과는 2021~2023 "수요붐" 국면에서만 유의(전체 IC +0.093, t 3.05; KOSPI +0.081, t 2.88), 2016~2020 평시엔 부재(+0.008, t 0.37). 즉 상시 알파가 아니라 레짐 조건부(state-dependent) 신호. 동시(coincident)≈0이라 "현재 매출 추종"이 아닌 진짜 선행이며, pooled corr은 이상치(소형 기저 폭발YoY)에 좌우돼 winsor 후 소멸 — 신호는 횡단면 breadth에만 존재.**

## 1. 실행 환경

| 항목 | 값 |
| --- | --- |
| 실행기 | 로컬 Windows 11 (CPU) |
| Python / 라이브러리 | 3.11.15 · OpenDartReader · FinanceDataReader · 자체 통계 |
| 데이터 출처 | DART 공개 API(분기 재무, 읽기전용·로컬 CSV) · 네이버 DataLab(검색) · FDR(유니버스) |

## 2. 실행 메타

- 코드 위치: worktree `sa-ml-longhorizon` working tree(미커밋). prod 쓰기 0. 팀 `app/**/dart/**` 코드 불변경(공개 API만 사용).
- 예측자(PIT): `abn` = 분기 검색량의 과거 4분기 대비 z(과거-only). 대조: `search_YoY`(전년동기比).
- 타깃: 단일분기 매출 YoY(전년 동분기比). DART 주요계정 누적/단일분기 basis 자동감지 후 de-cumulation.
- 평가: pooled corr + **분기별 횡단면 IC 평균**(+t), lag 0/1/2 스윕, era×market 분할, 분기 부호일관·LOO.
- 강건성: 매출YoY winsor 범위 −0.9 ~ +3.0 (소형 기저 폭발 방지).
## 3. 데이터 — 유니버스 · 자료

- 유니버스: KRX 시총상위 250(KOSPI 190 / KOSDAQ 60), SPAC·관리·환기·외국·리츠 제외. `select_krx_topn.py`.
- 자료:
| 자료 | 출처 | 저장(로컬·비추적) | 규모 | 기간 |
| --- | --- | --- | --- | --- |
| 분기 매출/영업이익 | DART 주요계정 | `dart_krx250.csv` | 216종목 매출보유 | 2015~2023(YoY용 2015 base) |
| 종목명 주간 검색 | DataLab | `stockname_krx250.csv` | 194종목 | 2016~2023 |

- 누수 차단: 예측자(분기 검색 abnormal)는 해당 분기말까지만, 타깃(차기분기 매출)은 ~4.5개월 뒤 공시 → 룩어헤드 없음.
## 4. 방법론 (판정 규칙)

- pooled: corr(검색, 매출YoY) 동시/선행. xs-IC: 분기마다 종목 횡단 corr → 평균 + t.
- **판정**: 선행(Q→Q+1) |t|>2 & 분기 부호 일관 & **era/market 전반 일관**이면 구조적 선행. 특정 era/market에만 있으면 국소.

| 횡단면 IC | 동시 Q | +0.044 | +1.84 | 28분기 |
| 횡단면 IC | **선행 Q→Q+1** | **+0.042** | **+2.09** | 28분기 |

| 검정 | 초기(KOSDAQ 9분기·2021~23) | 전수(250·28분기·2016~23) |

→ 초기 9분기는 전부 2021~23 안 → 기간효과를 신호로 오인. 평시 포함 시 평균 희석.

## 6. 해석 · 판정

- **레짐 조건부 선행 확인.** 검색 abnormal → 차기분기 매출은 **2021~2023 수요붐 국면에서 양 시장 모두 유의**(전체 t 3.05, KOSPI t 2.88). **평시(2016~2020)엔 부재**(t 0.37). 동시≈0이라 현재매출 추종 아닌 진짜 선행.
- **상시 알파로는 기각, 국면 조건부 신호로는 채택 가능.** 2021~22 리오프닝·2차전지·바이오 등 수요 급가속기에 소비자 검색이 매출을 약간 선행. 정상 국면엔 사라짐.
- **주의: 검색은 매출은 선행해도 *주가*는 선행 못 함**(동일 세션 선행 실험). 시장이 이미 반영하거나 매출→주가 연결이 약함 → 트레이딩 알파보다 **펀더멘털 나우캐스팅/수요-국면 플래그** 가치.
## 7. 이상치 · 주의 / 한계

- **레짐 표본 부족**: era당 11/17분기 — "2021~23 유의"도 11분기 기반(단일 거시국면일 수 있음). 다음 수요붐 전 검증 불가.
- **수요붐 교란**: 2021~23 효과가 "검색→매출"인지 "공통 거시충격(둘 다 동반 급등)"인지 분리 안 됨.
- **생존편향**(현재상장만), **pooled 무의미**(이상치), **search_YoY 무**(급증 z만), DART 주요계정 basis 혼재→자동 de-cumul.
- 데이터·로그 git 비추적.
