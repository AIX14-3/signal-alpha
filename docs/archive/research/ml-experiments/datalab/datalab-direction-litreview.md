# DataLab 방향성 신호 — 문헌 조사(deep-research) (2026-07-02)

**한 줄 결론: 검색량 단독으로 개별종목 "방향"을 만드는 검증된 방법은 문헌에도 없다(16개 소스 전부 매그니튜드·불확실성·단기반전으로 수렴). 방향의 유일한 현실 경로는 "부호는 뉴스·공시 감성에서, 크기·타이밍은 검색에서" 결합(fusion)이며, 이는 이미 세운 aggregator 융합 기획과 정확히 맞는다. 부차로 FEARS류 시장 반전 오버레이(~15bp·1~2일)가 성질이 다른 사용가능 값으로 남는다.**

> deep-research 하니스(5각도 웹서치→16소스 페치→73클레임→적대적 검증). **검증 상태**: 세션 한도로 종합·다수 검증이 중단 → 3개 클레임만 3표 완전검증(3-0), 나머지는 "소스 추출값"(반증 아님). 16소스가 일관된 그림. 우리 자체 실험(방향 10건 전부 NULL)과 교차확인됨.

## 배경 — 이미 기각한 방향 각도 (재시도 금지)

종목명 abn·특허/수요/의도 키워드·DART 이벤트 키워드·조건부 반전·prior-return 상호작용 = 전부 permutation+BH-FDR NULL. 확정 신호는 비방향(변동성·거래량 매그니튜드 + 차기매출 나우캐스트)뿐. → 이 조사는 **안 해본 새 각도**만.

## A. 감성/부호 실린 키워드 (valence-signed) — 대체로 실망

| 소스 | 발견 | 검증 |
| --- | --- | --- |
| Da-Engelberg-Gao 2015 FEARS (RFS) | 부호는 "종목별 호재/악재 쌍"이 아니라 **부정적 가계 우려어**(recession·bankruptcy·unemployment)를 시장수익에 t<−2.5로 골라 30개 집계 → **시장 전체** 지수. 단어 선별은 point-in-time(look-ahead 없음) | ✅ 3-0 |
| 대만 TPEx 소형주(48종목, 주간, 2016–19) | 양의 충격 후 검색 → 다음주 +수익 계수 +0.131(t1.90; 저어텐션 +0.186 t2.00). **단 순효과(레벨+상호작용)=0(Wald F0.07), 음의 충격은 무의미, 소형·저유동 한정** | 소스추출 |
| S&P500 2008–13 | 고검색→음수익이나 **부호가 표본마다 뒤집힘**(불안정) | 소스추출 |

- **판정**: 종목별 부호 실린 검색어는 방향 알파로 문헌상 지지 안 됨. 부호는 검색이 아니라 외부(뉴스/심리)에서 와야 함.
## B. FEARS류 시장 심리지수 — 방향 아니고 "단기 반전"

- FEARS↑ = 당일 S&P −19bp → **+7.1bp(k=1, 5%)·+7.3bp(k=2, 10%)로 되돌림**(2일 내 거의 원상복구), k=3~5 무의미. 누적 +14.4bp/2일. ✅ 3-0
- 효과는 **고베타·고변동·소형주(차익거래 어려운 종목)**에 집중, 대형주엔 약함(S&P→Russell2000으로 갈수록 강화).
- **판정**: 지속 방향이 아니라 ~15bp짜리 2일 반전. **종목 알파 아니고 시장 타이밍(리스크오프) 오버레이**. 우리가 안 만든 타깃이므로 후보 유지(단 저기대).
## C. 불확실성 채널 — 방향 없음

- GST(검색) 지수는 **수익과 음(−)·변동성과 양(+)** = 불확실성 프록시. R² 0.02~0.07 미미, 동시적. ✅ 3-0
- 종목 검색량은 **과거 수익을 따라갈 뿐 미래 방향 예측 못 함**(r²~0). 손실이 이익보다 검색 더 유발(하방 어텐션 비대칭)이나 이것도 **매그니튜드**지 방향 아님.
## D. 한국/네이버 특화

- KOSPI200에 구글 트렌드를 ML 입력으로 추가 → **방향 예측 개선 없음**(ANN/SVM 50~54% = 코인플립). 대형주 효율성과 일치.
- 네이버 DataLab abnormal 검색 → **실적 발표 underreaction**(어텐션→PEAD류) = 우리가 이미 찾은 매출 나우캐스트/SUE와 동일 현상.
## E. 융합(fusion) — 유일하게 방향에 희망적

- **Ranco et al. 2016 (PLOS ONE)**: 대형주 100종목(2012–13)서 **뉴스 감성(부호) + 브라우징/클릭(어텐션)** 결합이 **일중 가격 동학 예측 개선**.
- arxiv 1112.1051: **트위터 투자심리**가 방향 예측, 검색량 자체는 아님.
- **판정**: 부호는 뉴스/심리(외부)가, "언제·얼마나"는 검색이 담당 → 방향 회생 가능성. **심리지표로 방향을, 검색으로 게이팅/증폭.**

## 우리가 다음에 시도할 것 (순위)

**1순위 — 감성 융합 (기획과 정확히 일치) ★**

DataLab 어텐션(매그니튜드·타이밍) × **외부 부호 신호**(뉴스 감성 or DART 공시 톤/이벤트 부호)를 aggregator에서 결합. 검색이 방향을 못 만드니 **부호를 밖에서 가져오고 검색은 "지금 크게 반응 중"을 게이팅**. Ranco 2016이 대형주서도 먹힘을 시사. → 7-에이전트 융합 플랜의 첫 실증 대상.

**2순위 — FEARS류 한국 시장 반전 오버레이 (새 타깃)**

경기침체·실업·파산·공매도 등 가계 우려어를 DataLab 집계 → **KOSPI 단기(1~2일) 반전** 신호. 종목 알파 아니라 시장 리스크오프 타이밍. 효과 ~15bp·비용 취약·소형 집중이라 기대 낮음, 저비용 탐색용. 단어 선별은 FEARS식 PIT 회귀(look-ahead 금지).

**3순위 — 부호 키워드 쌍 (저비용·저기대)**

호재/악재·매수/매도 쌍의 검색 비를 횡단면 방향에 대조. 문헌상 null 가능성 높지만 문자 그대로는 미검정 → 싸게 falsify.

## 또 다른 막다른 길 (권장 안 함)

- 종목 고검색 → 방향(부호 불안정, 대만/S&P 순효과 0)
- crash 검색 → 하방 방향(비대칭은 매그니튜드지 방향 아님)
- 구글/네이버 트렌드를 대형주 방향 ML에 원피처 투입(KOSPI200서 개선 0 확인)
## 제약 재확인

우리 두 제약 — **≥1일 발행지연**(당일 매매 불가) + **대형주 효율적 가격** — 은 위 A·C·D를 특히 강하게 죽인다. B(시장 반전)와 E(융합)만 이 제약을 부분적으로 우회(전자는 1~2일 horizon, 후자는 부호를 외부서 조달).
