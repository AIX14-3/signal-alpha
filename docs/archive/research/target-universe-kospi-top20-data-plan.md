## 3. 우선순위 (빈칸 채우기 ROI 순)
1. **공매도 + 대차 + 신용잔고**(KRX, 전 종목) — 무료·대량, 수급/심리, 키움과 다른 축
2. **반도체 수출통계(관세청)** — 삼성·하이닉스·삼성전기 실적 선행 (반도체 3종목 = 시총 최상위)
3. **환율·미국증시(SOX)·VKOSPI** — 공통 레짐(예정+추천)
4. **ECOS 매크로(금리/경기선행)** — 금융·경기민감주
5. 섹터별 원자재(유가/구리/리튬) + NAVER 자사 채용 JSON

## 4. 구현 메모
- 이 20종목을 **`stocks.is_target = TRUE` 기준 유니버스로 고정**(seed `001_seed_stocks.sql` 또는 신규 마이그레이션으로 정렬). 현재 is_target 셋과 차이가 있으면 동기화 필요.
- 신규 소스는 기존 3계층(`raw_documents`/`*_raw_details`) + `source_type` enum 패턴 재사용. KRX 수급·공매도는 시계열이라 `*_raw_details`보다 전용 일자 테이블이 적합(채용 평가문서의 구조 논의 참고).
- KRX 로그인 이슈 → 무료 대안: 공공데이터포털 금융위 주식시세/지수시세 API(무인증 키), FinanceDataReader.
