## 1. 리포트 유형 전체 분류

증권사 리포트는 3개 레벨로 나뉜다.

| 레벨 | 분류 | 대상 | Signal α 활용 |
|---|---|---|---|
| L1 | 기업 분석 리포트 | 특정 종목 | **핵심 수집 대상** |
| L2 | 산업 분석 리포트 | 섹터 전체 | 제외 |
| L3 | 시장·전략 리포트 | 시장 전체 | 제외 |

Signal α는 삼성전자·SK하이닉스·네이버 3개 종목을 타겟으로 하므로 **L1 기업 분석 리포트만 수집**한다.

## 2. 수집 대상 리포트 상세

### 우선순위 기준

| 우선순위 | 기준 |
|---|---|
| ★★★ 필수 | 목표주가·투자의견 포함. 발간 빈도 높음. RAG 핵심 데이터 |
| ★★☆ 중요 | 목표주가 포함. 발간 빈도 중간. 보완 데이터 |
| ★☆☆ 보조 | 목표주가 없거나 발간 빈도 낮음. 맥락 보완용 |

---

### 2-1. Earnings Review (실적 분석 리포트) ★★★

| 항목 | 내용 |
|---|---|
| 한국어 명칭 | 실적 분석 / 실적 코멘트 / 어닝스 리뷰 |
| 발간 시점 | 분기 실적 발표 당일 ~ 발표 후 3영업일 이내 |
| 발간 주기 | 분기 1회 (연 4회: 1월·4월·7월·10월 실적 시즌) |
| 분량 | 2~5페이지 |
| 목표주가 포함 | 대부분 포함. 유지·상향·하향 명시 |
| 핵심 내용 | 실제 실적 vs 컨센서스 추정치 비교 (매출·영업이익·순이익), 어닝서프라이즈 여부, 목표주가 변경 이유 |
| RAG 활용 포인트 | DART 실적 공시와 직접 교차검증 가능. 가장 최신 컨센서스 반영 |
| 수집 우선순위 | ★★★ 필수 |

**발간 패턴 예시 (삼성전자 기준)**
```
실적 발표일 당일 오후:   키움·신한 등 빠른 증권사 2~3곳 발간
발표 다음날:             나머지 대부분 증권사 발간
발표 3일 이내:           전체 커버리지 증권사 발간 완료
```

### 2-2. Event Note (이벤트 노트) ★★★

| 항목 | 내용 |
|---|---|
| 한국어 명칭 | 이벤트 노트 / Flash Note / 뉴스 코멘트 |
| 발간 시점 | 공시·뉴스 발생 당일 ~ 익일 이내 |
| 발간 주기 | 비정기 (이벤트 발생 시 수시) |
| 분량 | 1~3페이지 |
| 목표주가 포함 | 일부 포함. 이벤트 성격에 따라 다름 |
| 핵심 내용 | 공급계약·M&A·CEO 교체·특허·규제 이슈 등 돌발 이벤트에 대한 즉각 투자 판단 |
| RAG 활용 포인트 | DART 공시와 가장 직접적으로 연결되는 리포트. 공시 임팩트 판단 교차검증 핵심 |
| 수집 우선순위 | ★★★ 필수 |

**주요 트리거 이벤트**
```
- 대규모 공급계약 체결 공시
- 실적 잠정치 공시 (어닝쇼크·서프라이즈)
- 자사주 매입·소각 결정
- CEO·임원 교체
- 정부 규제·세제 변경
- 경쟁사 이슈 (간접 영향)
```

| 발간 시점 | 분기 실적 반영 후 또는 반기 단위 |

| 분량 | 10~20페이지 |
| 목표주가 포함 | 항상 포함 |
| 핵심 내용 | 사업 구조 분석, 재무 모델 업데이트, 밸류에이션 근거, 향후 2~3개 분기 실적 추정치 |
| RAG 활용 포인트 | 컨센서스 추정치 집계 기반. 목표주가 트렌드 추적에 핵심 |
| 수집 우선순위 | ★★☆ 중요 |

| RAG 활용 포인트 | Earnings Review와 비교해 추정 정확도 분석 가능. DART 실적 공시 BEAT/MISS 판단의 기준선 |

### 2-5. Initiating Coverage (기업 첫 분석) ★☆☆

| 항목 | 내용 |
|---|---|
| 한국어 명칭 | 신규 커버리지 / 기업 분석 개시 |
| 발간 시점 | 해당 증권사가 해당 종목 커버리지를 시작할 때 1회 |
| 발간 주기 | 비정기 (증권사별로 커버 시작 시 단 1회) |
| 분량 | 20~40페이지 |
| 목표주가 포함 | 항상 포함 |
| 핵심 내용 | 사업 구조 전체, 경쟁 환경, 리스크 요인, 첫 목표주가. 가장 상세한 리포트 |
| RAG 활용 포인트 | 종목 배경 지식 구성용. 신규 증권사 커버 시작 자체가 긍정 시그널 |
| 수집 우선순위 | ★☆☆ 보조 |

**주의**: 삼성전자·SK하이닉스처럼 이미 모든 대형 증권사가 커버하는 종목은 신규 Initiating이 거의 없음. 수집되면 보너스 데이터 정도로 활용.

| RAG 활용 포인트 | 목표주가 트렌드 추적에 활용. 단, 내용이 짧아 RAG 검색 품질 낮음 |
| 수집 우선순위 | ★☆☆ 보조 |

## 3. 수집 제외 리포트

아래 유형은 수집하지 않는다. 수집하면 RAG 검색 노이즈가 증가해 분석 품질이 떨어진다.

| 리포트 유형 | 제외 이유 |
|---|---|
| 산업 분석 (Sector Report) | 특정 종목 데이터 없음. 섹터 전체 논의라 RAG 검색 노이즈만 증가 |
| 주간 산업 동향 | 단순 뉴스 요약. 투자의견·목표주가 없음 |
| 주간 시황 | 시장 전체 논의. 종목 특정 데이터 없음 |
| 월간 전략 | 거시 경제 논의. 종목 분석과 무관 |
| 연간 전망 | 연 1회 발간. 정보 신선도 낮음 |
| 채권 분석 | 주식 투자 분석과 무관 |
| 파생상품 분석 | 주식 투자 분석과 무관 |

## 4. 수집 기준 정책

### 기간 기준

| 기준 | 값 | 이유 |
|---|---|---|
| RAG 유지 기간 | 최근 90일 | 90일 이상 지난 리포트는 컨센서스 반영이 낡음 |
| 실적 시즌 확장 | 실적 발표 전후 14일 집중 수집 | 이 시기에 리포트가 평소 3~5배 발간됨 |
| 이벤트 노트 수집 주기 | 6시간마다 | 실시간은 파이프라인 복잡도 과도. 6시간 절충 |
| 그 외 리포트 수집 주기 | 매일 오전 7시 배치 | 전날 올라온 리포트 일괄 수집 |

### 수량 기준

| 기준 | 값 | 이유 |
|---|---|---|
| 종목당 RAG 최대 보유 수 | 20개 | 초과 시 오래된 순으로 archived 처리 |
| 증권사당 최대 보유 수 | 최신 3개 | 동일 증권사 리포트 중복 축적 방지 |
| 최소 수집 기준 | 목표주가 또는 투자의견 포함 | 둘 다 없으면 수집하지 않음 |

### 중복 처리 기준

```
pdf_url 기준으로 중복 확인
→ 이미 수집된 URL이면 스킵
→ 같은 종목·같은 증권사·같은 날짜면 최신 1개만 유지
```

## 5. 발간 시기 캘린더

### 연간 패턴

```
1월 (Q4 실적 시즌)
    - Earnings Preview: 1월 초~중순
    - Earnings Review: 실적 발표 후 (보통 1월 말~2월 초)
    - 리포트 집중 발간 기간: 약 3주

4월 (Q1 실적 시즌)
    - Earnings Preview: 4월 초~중순
    - Earnings Review: 실적 발표 후 (보통 4월 말~5월 초)
    - 리포트 집중 발간 기간: 약 3주

7월 (Q2 실적 시즌)
    - Earnings Preview: 7월 초~중순
    - Earnings Review: 실적 발표 후 (보통 7월 말~8월 초)
    - 리포트 집중 발간 기간: 약 3주

10월 (Q3 실적 시즌)
    - Earnings Preview: 10월 초~중순
    - Earnings Review: 실적 발표 후 (보통 10월 말~11월 초)
    - 리포트 집중 발간 기간: 약 3주

연중 수시
    - Event Note: 공시·뉴스 발생 즉시 (예측 불가)
    - Target Price Change: 시장 상황에 따라 수시
    - Company Visit Note: 월 1~2회 불규칙
```

### 3개 종목 연간 리포트 발간량 추정

| 종목 | 커버리지 증권사 수 | 연간 리포트 추정 수 |
|---|---|---|
| 삼성전자 | 20~25개사 | 200~300건 |
| SK하이닉스 | 15~20개사 | 150~220건 |
| 네이버 | 10~15개사 | 80~130건 |
| **3개 종목 합산** | | **430~650건/년** |

→ 90일 기준으로 RAG에 유지되는 리포트는 약 **110~160건** 수준

## 6. 증권사 우선순위

### 수집 우선 증권사 (커버리지·신뢰도 기준)

| 순위 | 증권사 | 선정 이유 |
|---|---|---|
| 1 | 신한투자증권 | 반도체·IT 섹터 커버리지 강함. 리포트 발간 빠름 |
| 2 | 미래에셋증권 | 3개 종목 모두 커버. 분량·품질 안정적 |
| 3 | 유진투자증권 | 실적 리뷰 품질 안정. 네이버 발간량·RAG 근거 품질 균형 |
| 4 | KB증권 | 목표주가 변경 빠른 편. 이벤트 노트 적극 발간 |
| 5 | 한국투자증권 | 삼성전자·SK하이닉스 심층 분석 강점 |
| 6 | NH투자증권 | 네이버 커버리지 강함 |
| 7 | 하나증권 | 반도체 섹터 특화 |
| 8 | 삼성증권 | 삼성전자 관련 상세 분석 |

### PDF 로컬 수동 저장 대상 (초기 RAG 구성용)

6주 프로젝트 특성상 PDF 자동 수집은 저작권 이슈와 기술 복잡도가 높다. 초기에는 아래 기준으로 수동 저장해 Local RAG를 구성한다.

| 저장 기준 | 내용 |
|---|---|
| 증권사 | 신한·미래에셋·유진 3개사 |
| 리포트 유형 | Earnings Review + Company Report 위주 |
| 기간 | **2025.07.01 ~ 2025.09.30** (초기 수집 고정 구간) |
| 종목당 목표 수 | 5~10개 |
| **총 저장 목표** | **45~90개 PDF** |

저장 경로 규칙:
```
/data/reports/
  samsung/        (005930)
  skhynix/        (000660)
  naver/          (035420)
    각 폴더 내: {증권사}_{날짜}_{리포트유형}.pdf
    예: shinhan_20260501_earnings_review.pdf
```
