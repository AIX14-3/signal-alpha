# DataLab — FEARS 시장 반전 오버레이 (② fusion-adjacent) (2026-07-02)

> worktree `sa-ml-longhorizon`. prod 읽기전용, 데이터 미커밋(연구), 도구만 브랜치 커밋. Naver 연구전용 키로 신규 수집(prod 쿼터 무관).
> 한 줄: **FEARS식 거시-공포어 검색지수 → KOSPI 단기 반전이 한국서 OOS 재현·유의(익일 +17.7bps/1SD·t4.5, 누적k1-2 perm_p0.013)** — 매그니튜드/나우캐스트 외 **DataLab 라인 첫 시장수준 방향성 신호**. 단 (a)반전이지 알파 아님 (b)~18bp 소 (c)**전량 [t→t+1] 창=발행지연 블록구간, 지연후 트레이더블 k≥2는 NULL** → 시장 리스크오프 *지표*로 유효, 트레이더블은 borderline.

## 배경
딥리서치: 검색 단독 per-stock 방향 없음. 유일 부차경로 = FEARS식 **시장수준** 집계 심리지수(Da-Engelberg-Gao 2015): 부정적 가계 우려어 검색 급등 → 당일 저수익 + 익일 반전. 우리는 미검정 → 한국 재현.

## 방법
- **수집**: 거시 우려어 30개(경기침체·실업·파산·공매도·주가폭락·서킷브레이커 등) 네이버 DataLab **일별** 2016~2026(`collect_datalab_terms.py`, 연구전용 키). 30/30 데이터 확보.
- **term shock** = PIT rolling-z(trailing 60거래일) of 일별 검색비율.
- **선별(train<2020)**: 각 term shock을 당일 KOSPI수익에 회귀→ **음의상관 top10**만 FEARS 구성(genuine 공포어). look-ahead 없음(train서만 선별).
- **FEARS_t** = 선별 term shock 평균. **OOS(≥2020)**: 표준화 FEARS_t → KOSPI ret_{t+k}(k=0~5) slope(bps/1SD)+t. 누적 k1~2 permutation(NPERM2000).
- 도구 `scripts/scratch_fears_reversal.py`(신규).

## 판정: 실재 시장 반전 신호 · 트레이더블은 borderline
1. **OOS·permutation 생존** = 실재. **매그니튜드/나우캐스트 외 첫 방향성(시장수준) 신호.**
2. **반전이지 지속 알파 아님** — 공포 과잉반응 되돌림. 종목 알파 아니라 **시장(KOSPI 지수) 리스크오프 오버레이**.
3. **~18bp/1SD/1일 = 작음** — 지수 선물/ETF 저비용 매매서만 경제성.
4. **★발행지연 함정(우리 핵심 제약)**: 반전은 전량 `[t→t+1]` 창. FEARS_t(당일 검색)는 **t+1에야 공개**(당일매매 불가). 지연 후 클린-트레이더블 horizon k≥2는 **NULL**(k2 +0.04 t0.01). 즉 신호는 실재하나 우리 제약이 막는 창에 정확히 위치 — 익일 아침 데이터 접근 속도에 트레이더빌리티 의존.

**결론**: FEARS = **유효한 시장 리스크오프 지표**(공포 급등→반등 예상, 제품의 시장수준 sentiment 오버레이로 사용가치). 트레이더블 알파로는 borderline(발행지연·소magnitude). 첫 방향성 생존이라 의미 있으나 종목 알파 아님.
