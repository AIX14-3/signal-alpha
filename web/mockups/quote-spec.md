# Signal α — 시세(Quote) 화면 스펙

> 목업 파일: `signal-alpha-quote-mockup.html` (단일 파일, 브라우저로 바로 열림)
> 디자인 기준: `README3.md` §2 디자인 시스템 · §3 `/quote` 라우트
> 원칙: 매수·매도 추천이 아닌 **데이터 정보 제공** 화면

---

## 1. 화면 목적

선택한 종목(예: 삼성전자 005930)의 **일봉 캔들 차트 + 종목 정보 + 시장 지수 + Signal α 교차검증 요약**을 한 화면에서 확인한다. 홈 화면의 인기 검색어/검색창에서 진입하는 상세 시세 화면이다.

---

## 2. 색상 규칙 (중요)

| 의미 | 색상 | 토큰 | 적용처 |
|---|---|---|---|
| **상승** | 🔴 빨강 `#dc2626` | `--up` | 캔들 양봉, 등락률(+), 거래량 바, 상승 지수 |
| **하락** | 🔵 파랑 `#2563eb` | `--down` | 캔들 음봉, 등락률(−), 거래량 바, 하락 지수 |
| 포인트(브랜드) | 🟠 주황 `#ea580c` | `--brand-600` | 20일 이동평균선, 기간 탭 활성, 즐겨찾기, 교차검증 카드 |

> 한국 주식 관례를 따른다(상승=빨강 / 하락=파랑). **주황은 UI 강조 컬러**로만 쓰고 시세 방향 색과 분리한다.

## 4. 목업 데이터

- **캔들**: 시드 고정 random-walk 42봉(open/high/low/close/volume). 약한 상승 드리프트로 자연스러운 추세 형성. 현재가·등락·종목정보 그리드는 **마지막 봉에서 자동 계산**되어 항상 일관됨.
- **이동평균**: 종가 20일 단순이동평균(SMA20), 주황 라인.
- **시장 지수**: KOSPI 2,612.45 (+0.62%, 빨강), KOSDAQ 745.30 (−0.41%, 파랑) + 스파크라인.
- **교차검증**: 방향성 일치율 87, POSITIVE, 주의근거 1건 (데모값).
- 시총/PER/PBR/52주 등 일부 지표는 사실적 데모 상수.

---

## 5. 차트 구현 노트

- 순수 **SVG**로 직접 렌더(외부 차트 라이브러리 없이 목업). 실제 구현 시 README3대로 **Recharts `ComposedChart`** 로 대체.
- 캔들 색: `close >= open → 빨강(양봉)`, 아니면 `파랑(음봉)`. 심지(wick)·몸통(body)·거래량 바 동일 색.
- 가격축: 우측 4분할 그리드 + 라벨. 현재가 점선 + 색상 태그.
- `viewBox` 기반 반응형(`preserveAspectRatio`), 폰 프레임 폭에 맞춰 스케일.

---

## 6. 접근성 · 규제 (UI 레벨)

- 방향을 색상에만 의존하지 않도록 **▲/▼ 기호 + 부호(+/−)** 를 병기.
- 모든 시세 화면 하단에 `※ 투자 권유가 아닌 정보 제공 목적입니다.` 고지.
- 점수 라벨은 "신뢰도"가 아닌 **"방향성 일치율"** 표기(`alignment_rate`).
- `needs_review` 발생 시 amber 배너 노출(요약 카드의 "주의근거" 자리와 연계).
