# Web 화면 목업 (Signal α)

앱 화면 템플릿 디자인 시안. 각 HTML은 **단일 파일**이라 브라우저로 바로 열어 확인할 수 있다.
디자인 토큰은 `README3.md`(Frontend Spec) §2 디자인 시스템을 따른다.

| 파일 | 화면 | 설명 |
|---|---|---|
| [`home.html`](./home.html) | 홈 | 히어로("주식에 대한 정보를 알아볼까요?") · 인기검색어 회전 검색창(삼성전자·하이닉스·네이버·현대차) · 실시간 인기 검색어 TOP 10 랭킹(미니 차트 포함) |
| [`quote.html`](./quote.html) | 시세 | 일봉 캔들 차트 + 거래량 + 20일 이동평균 · 종목 정보 12종 · 시장 지수 · Signal α 교차검증 요약 |
| [`quote-spec.md`](./quote-spec.md) | 시세 스펙 | 시세 화면 구성·색상 규칙·목업 데이터·차트 구현 노트 |

## 색상 규칙

- **상승 = 🔴 빨강(`#dc2626`) / 하락 = 🔵 파랑(`#2563eb`)** — 한국 주식 관례
- **포인트 = 🟠 주황(`#ea580c`)** — 활성 탭·이동평균선·CTA·교차검증 카드 등 UI 강조 전용

## 비고

- 모든 시세/점수/순위는 **데모용 목업 데이터**이며 차트는 순수 SVG로 그렸다(실제 구현은 Recharts 대체 예정).
- 화면 하단에 `※ 투자 권유가 아닌 정보 제공 목적입니다.` 고지를 포함한다.
