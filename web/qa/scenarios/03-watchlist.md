# 시나리오 03 — 관심종목 (시드 사용자)

**목표:** 관심종목 추가/삭제/영속성 검증(무제한).

**사전조건:** 무료 사용자 시드 + 쿠키 주입(로그인 상태).

**절차:**
1. `/report/[ticker]` 에서 관심종목 추가 버튼(`WatchlistButton`) 클릭 → 추가됨 상태로 토글 확인.
2. `/mypage` → 관심종목 탭에서 방금 종목이 목록에 보이는지 확인.
3. 다른 종목 1~2개 추가 → 목록에 누적되는지 확인(무제한).
4. 목록에서 한 종목 삭제 → 즉시 사라지는지 확인.
5. 페이지 새로고침 → 남은 항목이 유지되는지 확인(영속성).

**기대 결과:**
- 추가/삭제가 `POST /api/watchlists` / `DELETE /api/watchlists/{stock_code}` 로 반영되고,
  새로고침 후에도 `GET /api/watchlists` 로 동일 목록이 복원된다.
