# 시나리오 01 — 비회원/공개 영역 (무인, 인증 불필요)

**목표:** 로그인 없이 접근 가능한 표면이 정상 동작하는지 검증.

**사전조건:** 스택 기동(:3000/:8000). 쿠키 주입 없음(비회원 상태).

**절차 (browser-harness 자연어 구동):**
1. `http://localhost:3000` 진입 → 홈 히어로/검색 입력이 보이는지 스크린샷 확인.
2. 검색창에 종목명/코드(예: "삼성전자" 또는 "005930") 입력 → 검색 결과 목록 노출 확인.
3. 결과에서 한 종목 선택 → `/report/[ticker]` 진입.
4. 비회원 상태에서 **리포트가 잠금(🔒)** 이고, 비회원은 DART·네이버 소스만 블라인드로 보이는지 확인
   (나머지 소스 카드는 잠금/가림).
5. "로그인" 유도 CTA가 보이는지 확인.

**기대 결과:**
- 홈/검색/리포트 페이지가 500 없이 렌더(`web/src/lib/.gitignore`로 인한 lib 누락 회귀 주의).
- 비회원은 리포트 본문이 잠겨 있고, 소스 detail 클릭 시 로그인으로 유도된다.

**주의:** 검색 결과는 DB 적재 종목에 의존. 결과가 비면 종목/시그널 시드 여부를 먼저 확인.
