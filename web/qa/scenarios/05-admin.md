# 시나리오 05 — 관리자 대시보드 (선택)

**목표:** 관리자 로그인(이메일+비번, PortOne 무관) 및 대시보드 검증.

**사전조건:**
- 관리자 계정이 DB에 존재해야 한다. 부트스트랩 방법은 레포에서 확인 필요
  (admins 테이블 seed / 전용 스크립트 / ENV). 없으면 관리자 시드 절차를 먼저 만든다.
- 관리자 로그인은 `sa_admin` HttpOnly 쿠키 세션 → 쿠키 주입이 아니라 **실제 로그인 폼**으로 진행 가능
  (PortOne을 쓰지 않으므로 자동화 가능).

**절차:**
1. `/admin` 진입 → 미인증이면 로그인 폼 표시.
2. 시드된 관리자 이메일/비밀번호로 로그인 → `POST /api/admin/login`(sa_admin 쿠키 설정).
3. 사용자 목록/통계가 로드되는지 확인(`GET /api/admin/users`, `GET /api/admin/stats`).
4. (선택) 한 사용자에 구독 부여/해지(`adminSetSubscription`/`adminCancelSubscription`) 후 반영 확인.

**기대 결과:**
- 관리자 세션이 수립되고 대시보드 데이터가 표시된다.
- 구독 부여/해지가 해당 사용자에 즉시 반영된다.

**주의:** 관리자 계정 부트스트랩 방법이 레포에 없으면, 시드 스크립트에 admins INSERT(hash_password 사용)를
추가하는 것을 별도 작업으로 분리한다.
