# AGENTS.md

이 디렉터리는 Next.js 프론트엔드입니다. 마케팅용 껍데기가 아니라 실제 제품 경험을 구현하세요.

## API 경계

- 프론트엔드는 `agent-worker`가 아니라 `main-server`를 호출해야 합니다.
- 브라우저에서 backend scoring이나 분석 로직을 중복 구현하지 마세요.
- 사용 가능해지면 `final_signals` 기반 API 응답을 주요 표시 소스로 취급하세요.

## 제품 문구

투자 추천처럼 보이는 UI 문구를 사용하면 안 됩니다.

- "매수 추천"
- "매도 타이밍"
- "수익 보장"
- "지금 사야 할 종목"
- "추천주"

대신 아래 표현을 사용합니다.

- "데이터 방향성"
- "소스 간 일치도"
- "근거"
- "주의 근거"
- "추가 확인 필요"
- "사용자 판단 기록"

## UX 원칙

- 명시적으로 요청받지 않은 한 첫 화면은 landing page가 아니라 사용 가능한 dashboard 또는 workflow여야 합니다.
- 근거와 source 방향성을 명확히 보여주세요.
- 긍정 근거와 주의 근거를 분리해서 보여주세요.
- 일부 source 실패 또는 partial 상태를 숨기지 말고 표시하세요.
- Signal Journal 문구는 사용자의 주관적 복기 도구로 보이게 작성하세요.

## 프론트엔드 스택

- Next.js app router
- Tailwind CSS
- 이미 존재하고 유용한 경우 Zustand, Recharts

새 패턴을 도입하기 전에 기존 컴포넌트와 스타일을 우선 존중하세요.

## 테스트

이 디렉터리에서 실행합니다.

```powershell
npm test
```

UI를 변경했다면 반응형 레이아웃을 확인하고 한국어 텍스트가 버튼/카드 밖으로 넘치지 않게 하세요.
